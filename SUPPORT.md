# Support Guidelines

Thank you for using **Buckshot Tracker**! Here is how to find help, report issues, or get involved with the project.

---

## 1. Documentation & References

Before opening an issue, check the project documentation to see if your question is already covered:

- [Project Overview & Setup](README.md)
- [Architecture & Data Flow](docs/architecture.md)
- [Local Development Guide](docs/development.md)
- [Game Mechanics & Sources](docs/game-mechanics-sources.md)
- [Telegram Serverless SDK Reference](docs/tgcloud-sdk.md)

---

## 2. Reporting Bugs

If you encounter unexpected behavior or defects:
1. Search [existing GitHub issues](https://github.com/Greenhawk5/Buckshot-Tracker/issues) to ensure the issue has not already been reported.
2. If the issue is new, open a bug report using our [Bug Report Form](https://github.com/Greenhawk5/Buckshot-Tracker/issues/new?template=bug_report.yml).
3. Include device information, Telegram client version, and reproducible steps.

---

## 3. Feature Suggestions

To suggest an enhancement or gameplay feature:
1. Review [docs/game-mechanics-sources.md](docs/game-mechanics-sources.md) to confirm the idea aligns with single-player Buckshot Roulette mechanics.
2. Submit a request using our [Feature Request Form](https://github.com/Greenhawk5/Buckshot-Tracker/issues/new?template=feature_request.yml).

---

## 4. Security Concerns

For sensitive or security-related vulnerabilities, follow the private disclosure process documented in [SECURITY.md](SECURITY.md).
